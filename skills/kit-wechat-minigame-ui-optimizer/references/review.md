# Canvas 审查与验证

按“状态 → 绘制层 → 触控区域”检查实际受影响场景。

- HUD：分数、生命、暂停、结算与引导的层级，关键文字的对比和缩放。
- 坐标：逻辑分辨率、设备像素比、横竖屏与安全区；绘制和触摸反变换使用一致坐标系。
- 触控：视觉按钮与命中框对齐，按下/禁用反馈，弹层是否截断背后输入。
- 状态：开始、进行中、暂停、失败、成功与重试，根据修改范围验证。
- 精灵：源矩形、裁切、透明边、缩放清晰度与资源加载状态。
- 性能：逐帧分配、重复绘制、贴图开销；实际帧率必须测量，静态关键词不能证明性能。

Figma 节点只在设计任务需要且连接可用时读取。使用当前可用的微信开发者工具能力获取画面；桌面窗口截图包含工具 UI 时不能充当纯游戏画面。没有画面可交付静态结论，但不能声称运行验收完成。
