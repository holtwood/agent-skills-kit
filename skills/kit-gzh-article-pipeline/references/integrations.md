# 外部技能协作

用前读取当前已安装技能；缺失的纯写作能力可以按本 skill 直接完成。不要为了写一篇文章批量安装工具、重复审校或自动调用远端服务。下表是角色分工，准确命令以安装版本的入口和 `--help` 为准。

| 能力 | 首选/可选技能 | 调用边界 |
| --- | --- | --- |
| 中文自然编辑 | `humanizer-zh`；可选已有 `humanizer` | 一次只选一个。优先事实、限定和作者声音，不承诺 AI 检测结果 |
| Markdown 结构/排印 | `baoyu-format-markdown` | 在平台副本操作；纯格式任务保留现有标题与正文，避免其默认标题优化越界 |
| 公众号组件排版 | 已有 `gzh-design` | 默认引擎，使用当前组件和验证器；文章所需结构由内容决定 |
| Markdown → HTML | `baoyu-markdown-to-html` | 独立可选引擎；检查输出正文、图片路径和转换损失，不能冒充 gzh-design 已通过 |
| 技术图解 | `baoyu-diagram` | 用实际结构生成 SVG，并转 PNG；概念图不是产品运行截图 |
| 公众号预览/草稿及跨平台草稿准备 | 已有 `md2wechat` | 先确认 CLI 可用；按当前 discovery 判断能力与依赖，浏览器流程仅保存草稿 |
| 标题与选题 | 已有 `content-headline-hacker` / `topic-pool` | 已指定主题则不重选；不使用未经实测 CTR 或固定候选数量 |

## 转换引擎

默认延续 gzh-design。用户已有可用转换工具、指定引擎或文章需要其专长时选择其他引擎；只使用一个引擎渲染同一交付版本。md2wechat API 模式需其 API key，不能把远端失败静默改为另一种生成模式，也不能要求纯写作任务配置公众号凭据。

宝玉转换器使用 Bun/`npx bun` 和脚本依赖，确定输出后检查实际 HTML 与返回的图片清单。本地图片需在最终 HTML 所在位置可解析；远端图片可能下载到临时目录，交付前归档引用的真实文件。Mermaid 等代码块若回退为未渲染文本，须说明并补适用位图，不能报告图解已完成。

转换器默认移除首个标题。输入已经用 frontmatter 保存文章标题、正文直接从 H2/H3 开始时，显式使用 `--keep-title` 保留首个正文小节；只有首个 H1 确实重复文章标题时才让它移除。转换后逐项核对正文小节，不从命令成功或文字大致完整推断层级保真。

宝玉排印脚本会写回输入并可能规范化 frontmatter，先复制到平台工作副本；纯润色不调用它改代码、命令或元数据。语义 diff 仍由编辑者核对。

图解 PNG 转换脚本动态依赖 `sharp`，安装技能本身不等于运行依赖就绪。优先在该技能目录或单独缓存安装依赖，不修改用户网站 package.json。中文图中文字使用实际可用字体，并检查转换结果。

## 只借鉴方法的技能

- `khazix-writer`：材料理解、长文节奏、真实经历边界、分层自检。保留用户自己的声音，不继承其文化升维要求、标点禁令与口语词配额。
- `writer-skill`：区分素材来源、稿件/核查/配图分层、针对平台处理。默认不用其长入口、逐阶段确认或多代理流程。
- `Chinese-skill`：中文指代、修饰关系、术语和证据边界。其全局触发与专业文档语气不适合作为个人文章统一默认。
- 其他 Humanizer 中文分支可参考示例，已有一个合适编辑器时无需全部安装。
