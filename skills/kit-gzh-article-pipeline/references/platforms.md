# 母稿与全平台适配体系

本体系以**微信公众号为核心主力母港**，通过事实表与作者声音沉淀一份最严谨的 Markdown 母稿（`article.md`），再根据不同平台的读者载体与心智，派生为对应的平台版本。

运行 `python3 <SKILL_ROOT>/scripts/article_bundle.py platforms` 可列出已登记的全量平台、分类及稿件文件名。

---

## 1. 核心定位与平台分组

```
                      ┌───【核心主力母港】微信公众号 (wechat)
                      │    (双 HTML、1800×766 头图、1:1 方图、Base64内联)
                      │
                      ├───【长文技术社区】(longform) ── 个人博客(Astro)、知乎、掘金、CSDN、博客园、简书
【Markdown 事实母稿】 ───┤
                      ├───【全网资讯分发】(feed) ──── 今日头条、百家号、搜狐号、网易号
                      │
                      ├───【图文轻卡笔记】(notes) ─── 小红书、微信贴图/卡片 (3:4 竖版 / 1:1 方版)
                      │
                      └───【视听视频脚本】(video) ─── 抖音、哔哩哔哩 (B站)、微信视频号
```

| 分组分类 | 涵盖平台 | 核心载体形态 | 专用指引文档 |
| --- | --- | --- | --- |
| **主力母港 (wechat)** | 微信公众号 | 深度图文、原生组件排版、全选内联粘贴 | [排版与交付](delivery.md) |
| **长文与技术社区 (longform)** | Astro 个人博客、知乎、掘金、CSDN、博客园、简书 | 代码高亮、技术深度、逻辑自洽、纯净 Markdown | [长文社区指南](platforms/longform.md) |
| **资讯分发 (feed)** | 今日头条、百家号、搜狐号、网易号 | 泛科技读者、陈述型标题、无代码长篇、富文本导入 | [资讯分发指南](platforms/feed.md) |
| **图文笔记 (notes)** | 小红书、微信贴图/卡片 | 视觉与卡片第一、清单体、300-800 字极简 | [图文笔记指南](platforms/notes.md) |
| **视听脚本 (video)** | 抖音、哔哩哔哩、微信视频号 | 为耳朵写作、口播分镜对齐、前 3 秒钩子 | [视频脚本指南](platforms/video.md) |

## 2. 跨平台改写总原则

1. **事实母稿唯一，严禁分裂**：
   - 任何涉及功能、数据、版本、适用边界的事实修正，**必须先改母稿 `article.md` 与事实表 `facts.md`**，再向各平台稿同步；严禁单独在平台副本上造新事实。
2. **只有用户要求的目标才生成对应版本**：
   - 默认初始化仅创建主力公众号 `wechat`；用户明确要求多平台时通过 `--platforms <平台ID/分组名>` 指定（如 `--platforms longform` 或 `--platforms csdn xiaohongshu`）。
3. **平台稿是在母稿上做减法与重构**：
   - 长文社区：剥离公众号内联样式，保留完整代码与版本。
   - 资讯分发：将 80% 的实现代码收敛为步骤与效果图，解释专有名词。
   - 图文笔记：提纯为 4 张卡片大纲与清单体正文（须包含标题、正文、话题、卡片 4 个小节）。
   - 视频脚本：口语化重写，对齐时间线分镜（须包含标题、简介、口播稿、画面 4 个小节）。

## 3. 全网发布红线与合规

- **站外引流（绝对禁区）**：除个人独立博客外，知乎、掘金、CSDN、头条、百家号、搜狐、小红书等平台对正文出现公众号二维码、微信号、私信领取资料极其敏感，极易被判违规限流。平台稿默认一律删除所有公众号引流话术。
- **发布顺序与首发声明**：公众号原创、头条首发、百家号首发等与发布先后强相关。确定需要某平台首发权益时先发该平台；已全网发布的文章，在其他平台禁止虚假勾选“首发”。
- **AI 生成内容标识**：各平台已全面落地《人工智能生成合成内容标识办法》。若内容主要由模型协同撰写，交付说明中逐平台提示用户在发布时勾选后台的“AI 创作声明”标识。
- **广告法与违禁词**：全网各平台均对“全网第一”、“最强”、“100%解决”、“稳赚”等绝对化词汇严格审核，所有平台稿一律在成稿阶段彻底剔除。

## 4. 平台稿格式与粘贴纪律

- **公众号**：全选复制 `article-gzh-embedded.html` 直接粘贴到微信后台。
- **技术社区 (掘金/知乎/CSDN/博客园/简书)**：直接上传或粘贴 `article-*.md` 源码。若技术社区自带 Markdown 编辑器（如掘金/CSDN），优先保留 Markdown 原生代码块；图片通过平台编辑器本地批量上传。
- **资讯平台 (头条/百家号/搜狐/网易)**：后台编辑器不认 Markdown 源码。使用 Markdown 渲染工具生成不带花哨主题的纯净富文本页面，在浏览器全选富文本粘贴，再核对标题层级与图片居中。
- **矢量图转位图**：网站或母稿使用的 SVG 图解，向知乎、头条、搜狐、CSDN 等交付时一律转为高清晰度 PNG 位图，避免平台防盗链或不解析矢量文件。
