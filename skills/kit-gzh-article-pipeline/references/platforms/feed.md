# 资讯与分发平台适配指南

涵盖：**今日头条、百家号、搜狐号、网易号**。

这组平台依托算法信息流和搜索分发，受众以大众读者和泛科技用户为主，滑动速度极快，平台内容审核相对严格（对标题党、站外引流、广告法违禁词实行机器+人工双重审核）。

## 2. 核心适配与改写纪律

1. **降维解释与术语本地化**：
   - 读者多无编程背景。避免出现孤立的英文缩写或冷门名词（如将 AST 转换为“代码的抽象语法树结构，相当于代码的骨架”）。
   - 将母稿中 80% 的代码实现收缩为**核心逻辑步骤与运行效果**，用截图或清晰步骤代替大段代码。
2. **严防“标题党”红线**：
   - 严禁使用“竟然…”“万万没想到…”“震惊…”“彻底颠覆…”等悬念虚张声势句式。
   - 标题承诺的收益，前两段必须有事实承接；若标题提到数字（如“3 个技巧”），正文必须明确对应 3 点。
3. **彻底清理站外引流信息（封禁高危区）**：
   - 绝对禁止包含微信公众号二维码、微信号、添加好友、点击外链、“关注领资料”等文字。
   - 违者会被算法直接打入低质池或扣除信用分，甚至封禁账号。
4. **编辑器导入与格式粘贴**：
   - 此类平台后台富文本编辑器**绝大多数不支持 Markdown 源码直接渲染**。
   - 正确流程：在本地或浏览器中通过通用 Markdown 预览器打开 `article-*.md`，全选复制富文本，粘贴到平台后台。
   - 检查粘贴后的多级标题（H2/H3）、无序列表和图片是否正常居中展示。
5. **合规词与 AI 声明门禁**：
   - 《反不正当竞争法》与《广告法》红线：禁止出现“全网第一”、“最强”、“100%解决”等词。
   - 勾选各平台后台的“AI 辅助生成声明”选项（若内容主要由模型协同撰写）。
