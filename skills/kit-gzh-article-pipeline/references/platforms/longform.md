# 技术社区与长文博客适配指南

涵盖：**个人博客（Astro/独立站）、知乎、掘金、CSDN、博客园、简书**。

这组平台读者多为开发者、技术爱好者和专业从业者，对代码完整性、逻辑深度和实操可复现性有天然要求。母稿在此主要做“语境与排版微调”，不破坏事实骨架与技术准确度。

---

| 平台 | 读者心智 | 标题策略 | 正文与排版重点 | 交付文件名 |
| --- | --- | --- | --- | --- |
| **个人博客 (Astro)** | 长期技术沉淀、检索归档 | 结构化、含技术栈/版本号、SEO 友好 | 遵循站点 schema、去除导流与公众号花哨样式、代码全量高亮 | `article-astro-body.md` |

## 2. 核心适配纪律

1. **从公众号母稿做“样式脱壳”**：
   - 微信公众号的富文本 HTML 含有内联样式（span、font-size、特定配色边框）。**严禁将公众号 HTML 直接贴入技术社区**，会导致代码块无法识别或排版崩坏。
   - 使用母稿 `article.md` 直接微调生成对应的 Markdown 平台版本（或借助纯净 Markdown 编辑器导入）。
2. **代码块与高亮保真**：
   - 技术社区的代码块必须保留正确的语言标记（如 ```python、```typescript）。
   - 长代码段添加关键注释；伪代码或终端命令清楚标注输入与预期输出。
3. **图解与媒体**：
   - SVG 矢量图在掘金/CSDN/简书等编辑器可能无法正常解析或被当作附件，**一律上传导出的高清晰度 PNG 位图**。
   - 保留图注与架构说明文字。
4. **技术术语与版本保护**：
   - 保留清单 `must_keep` 中的版本号、核心库依赖、限制条件。不能为了“通俗”把 Python 3.12 模糊成“最新版”。
5. **公众号转载稿（知乎/掘金）**：
   - 公众号稿为手机短段而写，转到知乎/掘金时可合并过碎的短段，补回公众号里删减的代码、版本与参考链接；去掉只对公众号有意义的话（"点击阅读原文""文末留言"）。
   - 知乎：标题可改成问题或判断句，开头两段直接给结论；学习笔记类适合回答相关问题后再发文章。掘金：刷题心得、工程实践优先，标题带技术关键词，正文代码完整。
   - 作者名、头像、简介与公众号一致，文末身份一句话见 [栏目、标题与个人品牌](../columns.md)。
6. **站外引流规范**：
   - 个人博客可自由放置 GitHub、联系方式；
   - 掘金、CSDN、知乎对正文出现公众号二维码、微信号、私信返利极其敏感，违规将触发限流甚至封禁。结尾建议替换为：“欢迎在评论区交流”，或仅在平台允许的个人主页/简介处沉淀。
